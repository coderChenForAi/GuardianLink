# GuardianLink

两台安卓手机互为"守护对"：**被监护人离开 WiFi 覆盖范围 / 蓝牙断开时，两台手机同时最大音量响铃告警**，被监护端会把 GPS 位置定时上报到飞书群机器人（带高德地图链接，点开直接看位置）。不需要自建服务器。

## 功能

- **WiFi 模式**：两台手机连同一路由器。被监护端监听自身 WiFi 断开（默认宽限 5 秒防抖动）；两端每 5 秒互发 UDP 心跳，任一端连续 15 秒收不到对端 → 本机告警。**对端 App 被杀/手机没电也会触发告警**。
- **蓝牙模式**：两台手机系统配对后 RFCOMM 直连（近距离 ~10-30 米防走散），链路断开 10 秒宽限自动重连，仍失败则两端告警。
- **飞书位置上报**：告警时立即取 GPS 上报 + 监护期间每 30 秒定时上报（间隔可调），WGS-84 自动转 GCJ-02 生成高德地图链接。webhook 留空则只本机响铃不上报。
- **告警**：ALARM 音频流拉满音量循环警笛 + 循环震动 + 锁屏全屏告警页；授予勿扰权限可穿透勿扰。
- 支持机型：Android 8.1+（minSdk 27）。

## 如何拿到 APK（不需要装 Android Studio）

1. 在 GitHub 新建一个仓库，把本目录全部文件推送上去（含隐藏目录 `.github/`）：

   ```bash
   cd GuardianLink
   git init && git add -A && git commit -m "init"
   git remote add origin https://github.com/<你的用户名>/GuardianLink.git
   git push -u origin main
   ```

2. 打开仓库的 **Actions** 页 → 选最新一次运行 → 下拉 **Artifacts** → 下载 `GuardianLink-debug-apk`。
3. 传到手机安装（允许"安装未知应用"）。

也可以本地装好 Android SDK 后直接 `./gradlew assembleDebug`。

## 两台手机怎么用

### WiFi 模式（离开家/小区告警）

1. 两台手机连**同一个路由器**（不要用开了 AP 隔离的访客网络），都安装 App。
2. 孩子手机：选角色"被监护人" → 点"开始监护"（首次需授予定位/通知权限 + 申请电池白名单）。
3. 家长手机：选角色"监护人" → 点**"扫描对端"**，选择发现的设备完成绑定 → 点"开始监护"。
4. 扫描不到时用"手动填 IP"（孩子手机 IP 在 设置→WLAN 里看；建议在路由器上给孩子的手机做 DHCP 静态绑定）。
5. 之后孩子带手机离开 WiFi 范围：约 5 秒内孩子手机响铃，约 15 秒内家长手机响铃，家长飞书群收到位置。

### 蓝牙模式（商场/景区近距离）

1. 两台手机先在系统设置里完成蓝牙配对。
2. 两台 App 内切到"蓝牙模式"，各自"选择蓝牙设备"选中对方，点"开始监护"。
3. 被监护端自动做服务端、监护端做客户端，断开 10 秒内未重连则两端响铃。

### 飞书机器人配置（可选但推荐）

1. 飞书群 → 设置 → 群机器人 → 添加"自定义机器人" → 复制 Webhook 地址。
2. App 内 ⚙ 设置 → 粘贴 Webhook URL → "发送测试消息" → 群里收到即成功。
3. 默认告警时立即上报一次 + 每 30 秒定时上报；不需要可在设置里关掉"监护期间定时上报位置"。

## 保活（漏报的最大敌人）

App 用前台服务 + 持锁运行，但仍需手动做两件事：

1. 首页红色横幅 → "申请白名单"（忽略电池优化）。
2. 品牌设置指引：
   - **小米/红米（MIUI/HyperOS）**：应用信息 → 自启动 ✅；省电策略 → 无限制；锁定任务卡片。
   - **华为/荣耀（EMUI/HarmonyOS）**：设置 → 电池 → 启动管理 → 手动管理，三项全开。
   - **OPPO/vivo**：电池 → 允许后台高耗电；最近任务下拉锁住。
   - **Pixel/原生**：申请白名单即可。

## 参数默认值

| 参数 | 默认 | 说明 |
|---|---|---|
| WiFi 断开宽限 | 5s | 防路由抖动误报 |
| 心跳间隔 | 5s | UDP 单播 |
| 心跳失联判定 | 15s | 约 3 个心跳未收到 |
| 蓝牙宽限 | 10s | 期间自动重连 |
| 位置上报间隔 | 30s | 监护期间定时上报 |

## 已知限制 / 后续路线

- WiFi 模式检测的是"离开该路由器覆盖"，不是精确距离；蓝牙模式是近距离（10-30 米）。两者互补。
- 路由器开 AP 隔离（访客网络常见）会让心跳完全不通，首页会一直"连接中"——换主网络。
- 孩子直接卸载 App 时家长端会因心跳超时告警，但"防卸载"需要设备管理员方案，v1 未做。
- 飞书机器人自签名校验、SSID 绑定、轨迹记录：v1.1 候选。

## 工程结构

```
app/src/main/java/com/guardian/link/
  ui/        引导页 / 首页 / 设置页
  service/   GuardService（前台服务 + 状态机编排）
  core/
    wifi/    WiFi 监控、UDP 心跳、对端发现
    bt/      蓝牙 RFCOMM 链路
    alarm/   告警（铃声/震动/全屏页）、勿扰穿透
    locate/  定位（GMS + 无 GMS 回退）、WGS84→GCJ02
    feishu/  飞书 webhook 客户端
  data/      DataStore 设置仓库、模型
```

CI：push 后 GitHub Actions 自动构建 debug APK（`.github/workflows/build.yml`）。
